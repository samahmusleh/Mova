# Design

**Figma file (design system + clickable prototype):** https://www.figma.com/design/htZnKQh0CrRfJGSuiEW57J/Michigan-DevFest

- **Device:** iPhone 17 Pro, 402 × 874pt. Safe areas 62pt top, 34pt bottom; 16pt side margins.
- **Direction:** playful and gamified for teens · Detroit Blue + Electric Lime, plus purple, pink and orange for rewards · Nunito headings + DM Sans body · rounded shapes · chunky "pressable" buttons · light and dark modes.
- **Accessibility:** text colors checked against WCAG 2.2 AA; 44pt minimum touch targets; reduced-motion fallbacks for every animation; calm, no-confetti treatment for sensitive moments.

## Pages in the Figma file
Cover · Brand & Logo · Foundations (tokens, type, spacing) · Icons · Core UI · Mentoring · Gamification · Navigation · Screens (mentor and mentee dashboards, light/dark) · Prototype

## Prototype flows (Prototype page, present mode)
1. **Kayla slips and comes back** (start here): home screen → launch → Kayla checks in "family stuff" → Jaylen gets a MOVA tip and sends a drafted, safety-checked message → Kayla does a catch-up question → comeback → Jaylen sees the win
2. **Mentor onboarding:** crew code → welcome (crew matched)
3. **Rewards:** 7 incentives with "almost there" glow → reward unlocked celebration
4. **Advisor:** FERPA acknowledgement → dashboard → reply to help requests → review and approve mentor logs → mentor profile
